# Signals desktop releases

Download Linux x64 AppImage and Debian installers from [Releases](https://github.com/kernelwhisperer/signals-releases/releases).
Signals requires a network connection for data and authentication.

The application checks for updates and asks before download and restart.
Debian updates require administrator approval. On NixOS, keep the AppImage outside the Nix store and use the documented runtime launcher.

This repository contains downloads and update metadata. Application source remains private.
The bundled frontend and Electron JavaScript are readable from installed packages.
